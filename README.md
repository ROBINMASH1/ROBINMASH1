## 🚀 Featured Project

# 🔗 Tawtheeq — Academic Credential Verification Platform

A blockchain-powered credential verification platform designed to prevent certificate fraud and provide trusted academic credential validation.

### Key Features

✅ Blockchain-backed certificate verification

✅ Certificate issuance, validation, and revocation

✅ Multi-role access management

✅ JWT Authentication & Authorization

✅ OTP-based account recovery

✅ Role-Based Access Control (RBAC)

✅ Audit logging and activity tracking

✅ Secure RESTful APIs

### Architecture

**Frontend**

* React

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

**Infrastructure**

* DigitalOcean

**Security**

* JWT Authentication
* Role-Based Access Control
* Secure API Design

### My Contributions

* Designed and developed the backend architecture
* Implemented authentication and authorization workflows
* Built certificate lifecycle management features
* Developed audit logging and monitoring systems
* Integrated blockchain verification processes
* Deployed and maintained production infrastructure

### Impact

Tawtheeq provides a secure and transparent method for verifying academic credentials, reducing fraud risks while improving trust between universities, students, and employers.
